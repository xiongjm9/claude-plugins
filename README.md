# Antigravity Custom Theme

暖陶燕麦 · 精致（浅色）+ 深炭琥珀（深色），可在主题切换器里选用；另保留官方原版 `stock`。

## 安装

1. 关掉 Antigravity
2. 在本目录执行：`node install_permanent.js`
3. 或双击桌面「一键恢复Claude橙色UI.bat」

已开着的窗口可再跑：`node inject_live.js`

## 文件

- `current.js` / `current.css` — 主题本体
- `install_permanent.js` — 永久注入
- `inject_live.js` — 热注入
- `CHANGELOG.md` — 变更说明
