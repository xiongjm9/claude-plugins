# dsh-antigravity-skin

DeepSeek Harness 的独立外观插件。提供铝灰、瓷白、雾蓝、沙岩、苔绿五套浅色皮肤，以及强调色、实色 / 磨砂 / 通透材质、渐变或图片壁纸。

配置只保存在本机 `~/.dsh/antigravity-skin.json`，壁纸在 `~/.dsh/antigravity-skin-wall.*`。不会读写 Antigravity。默认是铝灰、实色面板、极光背景、强调色 `#0071E3`。

设置里的名称是「个性化皮肤」。文件夹和插件名暂时保持 `dsh-antigravity-skin`，已经装过的不用重新添加。
