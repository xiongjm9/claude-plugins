# 代发指令包（给 Grok Bot / 另一会话执行时用）

仅当用户要求代发、转发、让其他 agent 出片时使用。本机自己跑 `/grill-video` 不必套这层。

## 输出格式（第一人称，可直接粘贴）

```
【代发指令包 · grill-video】
你是出片执行方。只按下列参数生成，不要改分镜创意，不要追问。

目标：只生成 1 条视频（或先 1 张首帧图，等我确认再出视频）。
平台/工具：…
画幅：…（以首帧实测为准，与此不一致必须重出）
时长：…s
分辨率：…
模式：惊艳向/平实
是否钉尾帧：是/否
参考附件：…（路径或「见下一条消息」）

【分镜摘要】
…

【首帧图提示词】
…

【动态提示词】
…

【完成判据】
- 首帧宽高比 = …
- 成片时长 ≈ …s，有音轨（如需要）
- 交付文件完整路径
- 不要额外生成第 2 条

【附件失败备用】
若收不到附件：用首帧提示词先 image_gen；勿改主体与光色；完成后注明「未使用用户参考图」。
若视频工具报 ZDR/额度/升级：原话返回，只保留提示词，勿重试刷量。
```

参数写死，不留「适当调整」。一次包只对应一条成片任务。
