# 主题变更

## 2026-10-29 只要浅色四套

退役并删除自定义深色与旧自定义浅色：`graphite-dark`、`graphite-light`、`claude`、`claude-dark`。这些旧 id，以及空偏好、`gemini`、其它未知 id，都映射到 `warm-rice`。切换器五项，默认第一项。`stock` / 「官方原版」的 CSS 未改。

1. `warm-rice` / 「暖米」默认
   - 页底 `#F7F3EC`，侧栏与顶栏不透明 `#FFFAF5`（`--sidebar: #FFFAF5`）
   - 正文 `#2C2A26`，次级 `#6B6560`，发丝 `#E5DFD4`
   - 主色鼠尾草绿 `#0F766E`，只用于主按钮、焦点环、选中 2px 条。无橙色
   - 标题栏 `#FFFAF5`，符号 `#2C2A26`
   - 正文对比：页底 12.95:1，侧栏 13.81:1。次级在页底 5.19:1、侧栏 5.54:1。白字在主色上 5.47:1
2. `paper` / 「纸白」
   - 页底 `#FAFAF8`，侧栏与顶栏 `#FFFFFF`
   - 正文 `#1A1A1A`，次级 `#6B6B6B`，发丝 `#E8E8E4`
   - 主色墨蓝 `#2563EB`。白字在主色上 5.17:1。正文在页底 16.65:1，次级 5.10:1
3. `cloud` / 「云灰」
   - 页底 `#F4F6F8`，侧栏与顶栏 `#FFFFFF`
   - 正文 `#1B1F24`，次级 `#5C6570`，发丝 `#DCE1E6`
   - 主色石板蓝 `#3B82F6`。正文在页底 15.29:1，次级 5.46:1。白箭头在主色上 3.68:1（图标非文本对比）
4. `celadon` / 「青瓷」
   - 页底 `#F3F7F5`，侧栏与顶栏 `#FFFFFF`
   - 正文 `#1C2A24`，次级 `#5A6B63`，发丝 `#D5E3DC`
   - 主色 `#0D9488`。环境光是极淡青绿，没有第二色相。正文在页底 13.82:1，次级 5.23:1。白箭头在主色上 3.74:1

动效沿用克制方案。`prefers-reduced-motion: reduce` 时不做位移、缩放和环境光，只保留颜色或短透明度：

- 主题相关色约 `240ms`
- 悬停背景约 `120ms`，纯悬停规则包在 `@media (hover: hover)` 里
- 发送按钮按下 `scale: 0.97`，只在 `no-preference`，且排除 disabled
- Composer 聚焦：1px 主色边 + 4px 软光环
- 侧栏选中：左侧 `2px` 主色条
- 浮层 / 菜单：`opacity` + `translateY(4px → 0)`，`160ms`；减少动效时只淡入透明度
- 页面 mesh：36s 极淡单色环境光。暖米是鼠尾草绿，青瓷是青绿，没有彩虹
- 切换主题当帧加上 `ag-theme-switching`，关掉过渡

硬约束仍在：`--sidebar` 不透明实色，嵌套 `.bg-sidebar` 透明，吸顶标头视口固定渐变，媒体胶囊 `absolute`。未改 `install_permanent.js` / `inject_live.js`。

## 2026-10-29 石墨银重做

退役 `claude` / 「暖陶燕麦 · 精致」和 `claude-dark` / 「深炭琥珀」。旧偏好 id 会映射到对应新主题。切换器只保留三项。`stock` / 「官方原版」的 CSS 未改。

  - 标题栏 `#FFFFFF`，符号 `#1D1D1F`
- `graphite-dark` / 「深空石墨」
  - 真黑底 `#000000`（`--sidebar: #000000`）
  - 卡片 / 菜单 `#1C1C1E`，再抬一层 `#2C2C2E`
  - 正文 `#F5F5F7`，次级 `#A1A1A6`
  - 系统蓝 `#0A84FF`，用法与浅色相同。无橙色、金色、琥珀
  - 标题栏 `#000000`，符号 `#F5F5F7`
  - 分层靠炭色和发丝边，去掉 `0 16px 40px` 一类脏灰大阴影

动效（`prefers-reduced-motion: reduce` 时不做位移、缩放和环境光，只保留颜色或短透明度）：

- 主题相关色（背景 / 边框 / 文字）约 `240ms` ease，发送按钮颜色 `200ms`
- 悬停背景约 `120ms`，并包在 `@media (hover: hover)` 里
- 发送按钮按下 `scale: 0.97`，只在 `no-preference`，且排除 disabled
- Composer 聚焦：1px 系统蓝边 + 4px 软光环，`240ms` 淡入
- 侧栏选中：左侧 `2px` 系统蓝条，`box-shadow` 约 `200ms`
- 浮层 / 菜单：`opacity` + `translateY(4px → 0)`，`160ms`；减少动效时只淡入透明度
- 页面 mesh：36s 极淡冷色环境光漂移，没有彩虹渐变。浮层毛玻璃 `blur(20px) saturate(180%)`

硬约束仍在：`--sidebar` 不透明实色，嵌套 `.bg-sidebar` 透明，吸顶标头视口固定渐变，媒体胶囊 `absolute`。未改 `install_permanent.js` / `inject_live.js`。

## 审美精修

- 圆角收成同一套：`6 / 8 / 12 / 16 / 9999`。用户气泡 14、菜单 10、行内代码 5、标签关闭 4 都对齐到这套。切换器下拉外圆角 12、内项 8，和 4px 内边距同心。
- 阴影改成短 key + 轻 ambient，再加一条内顶发丝高光。去掉 `0 16px 40px` 这一类脏灰大阴影。深色不再靠大块纯黑投影，靠炭色层次和发丝边分开。
- 毛玻璃收到 `blur(12px) saturate(108%)`。结构边框用暖中性发丝，不再用桃橙色粗边。
- 浅色实底主色从 `#CC5A36` 收到同一暖橙色相的 `#AB4C2D`。白字在实底上 5.52:1，主色文字在侧栏 `#EFE8DC` 上 4.54:1。次级文字统一为 `#6E665C`，在侧栏上 4.64:1。正文仍是 `#2E2A25`。
- 深色底从 `#171513` 抬到深炭 `#1C1916`，菜单一层 `#2C2824`。琥珀 `#E8A85C` 只留在 primary、焦点环、会话/问答选中和文字选区。悬停改成暖中性发丝，不再整面铺金。主色上的文字是 `#1A140E`（8.86:1）。次级文字 `#C4B6A8`，在最浅炭底 `#2A2622` 上 7.58:1。
- Composer 聚焦改成 1px 色边 + 3px 低透明环，发送按钮去掉色晕，按下在 `prefers-reduced-motion: no-preference` 下缩到 `0.96`。
- 正文字号 15px、行高 1.6、字距 0。标题字距收回 0（苹方全角，不再额外加正字距）。缩放百分比使用 `tabular-nums`。
- `stock` 官方原版主题未删。看图胶囊仍是 `absolute`。共享胶囊模糊从 20px 收到 12px，悬停不再放大到 1.08。

## 重新注入

关掉 Antigravity 后任选其一：

- 运行桌面上的「一键恢复Claude橙色UI.bat」
- 或在本目录执行 `node install_permanent.js`

已经开着的窗口也可以再跑一次 `node inject_live.js` 做热注入。切到「深炭琥珀」后若标题栏按钮区没立刻变色，重开一次窗口即可。
