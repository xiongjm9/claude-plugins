# 主题变更

## 2026-11-05 语音按钮

- 输入栏语音胶囊不再是一颗纯黑圆。主题把 `--background` 设成透明后，官方 `text-background` 波形跟着透明。
- 闲置态改成和「添加上下文」同一档的线框按钮，图标用正文色。录音中的官方样式不动。健康检查会在波形透明或胶囊又变成实心圆时报警。

## 2026-11-01 顶栏入口与视觉交互精修

- **顶栏入口全面重构**：采用方案 A 极简精细矢量调色盘（SF Symbols / Fluent 规范矢量 Glyph），彻底移除原先破坏顶栏秩序的实心彩色大圆点与中文字块；尺寸为 26×24px 极简幽灵按钮，完美 1:1 融入 IDE 顶栏工具区，内置随主题强调色实时变色的微型调色光斑与换色弹簧脉冲；Tooltip 与无障碍标签动态指示当前主题名称。
- **动效规范合规统一**：清除 `src/base.css` 中残留的 `@media (prefers-reduced-motion)` 媒体查询，统一收归由 `html[data-sk-motion]` 驱动；发送按钮及各类动效严格限定使用 `transform` / `opacity`。
- **Composer 输入框聚焦光晕**：打字聚焦态从单一外框升级为带有呼吸感的双层漫发光（`3.5px` 强调色漫漫光晕 + `0.5px` 顶层白发丝高光），交互手感更润泽。
- **外观面板（Studio）环境质感提升**：浮层采用 14px 连续圆角、1px 精细发丝边与双层环境漫反射投影，消除粗糙黑边。
- **跨平台高清排版字体栈**：正文优先匹配 Segoe UI Variable / SF Pro / 苹方 / 微软雅黑，消除 Windows 下字体虚焦；代码字体优先调用 Cascadia Code / JetBrains Mono。

## 2026-11-01 界面汉化

- 新增界面语言：中文（默认）/ English，在外观面板切换，官方原版皮肤下也可用
- 词典 `src/i18n-zh.js` 独立编写（约 500 条 + 12 条动态模式），覆盖导航、侧栏、输入框、通用操作、状态、智能体与设置页常用文案
- 只改显示文本、`title` 和 `placeholder`；不改 `aria-label`（宿主样式靠它定位按钮），不进代码、编辑器、终端、消息正文和输入内容；原文记在旁边，切回 English 时还原
- 健康检查新增「界面汉化」项
- 设置页补齐：通用、会话与权限、浏览器、外观、通知、自定义、应用、反馈、快捷键、模型与用量、开发者、项目设置，约 145 条 + 10 条动态模式（项目数、会话数、token 明细、剩余额度时长）

## 2026-10-31 动效

- 换皮肤：View Transition 从点击处圆形展开（620ms）；强调色、材质、壁纸等离散改动做 200ms 淡入淡出；滑杆与取色器拖动不做整窗过渡
- 面板：打开时分节依次浮入（每节间隔 28ms）、选中项回弹、皮肤卡片跟随指针倾斜并带高光、标题栏色点换色时回弹、提示条弹簧进出
- 丰富档：壁纸 48s 缓慢漂移，只动 transform，窗口失焦或隐藏时暂停
- 新增「动效」档位：丰富 / 标准（默认）/ 关闭；系统「减少动态效果」打开时默认关闭，可在面板里选择仍然开启
- 插件动画统一由 `html[data-sk-motion]` 控制，不再各处单独读 `prefers-reduced-motion`；应急快捷键切换刻意不做动画
